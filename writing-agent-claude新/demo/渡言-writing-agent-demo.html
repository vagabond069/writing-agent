8 阶段写作链路

对齐出的核心论点，沿着项目 agent/workflow-writing.md 定义的标准链路推进。每个阶段只做一件事，产出可追溯。

为无名黄昏发明节日

运行 · experimental · draft-v2 ｜ 风格：戴锦华向 ｜ 已生成 fact-check.md ✓

有时候，一组看上去几乎没有逻辑的「喜欢」和「不喜欢」，反而比任何完整、自洽、可向他人交代的自我介绍，更能泄露一个人真正想要的生活。它当然可以被读作一种私人趣味、一份情绪化清单、一张审美地图，但问题也许并不止于此。真正值得追问的，不是这些偏好究竟够不够特别，而是：为什么今天的人，会如此强烈地需要借由这些意象，为自己勾勒一个尚未完全被生活收编的世界？

在这份碎片里，最动人的并不是某个具体物本身，而是它们共同指向的一种愿望：希望生活里仍有某种东西，不必立刻被解释，不必迅速被归类，不必马上被命名成一种关系、一种人格、一种风格、一种内容。人们迷恋的也许不是这些对象本身，而正是这种尚未被钉死的状态——一种仍可犹疑、仍可偏航、仍可为自己偷偷发明另一种节奏的生活可能。

也正因此，便利店月光宴才显得如此可贵。它一点也不宏大，甚至拮据得近乎寒酸；但它把一种今天已经稀缺的能力重新带回来了：让一个普通时刻拥有被珍视的资格。它并没有逃离现实，它只是悄悄改写了现实的使用方式。所谓仪式感，也许并不是昂贵、盛大、值得拍照留念的东西，而不过是：你肯不肯承认，这个原本毫不起眼的夜晚，也配拥有一点点节日的尊严。

如果把这些私人小提案放在一起看，我们会发现，它们真正共享的并不是「文艺感」，而是一种对被完全命名的生活的拒绝。在今天，太多事情都必须迅速被定义：关系要被定义，爱好要被定义，连休息也要被定义成某种高质量恢复。人真正争夺的往往不是什么宏大自由，而只是一点仍可不被立刻解释的余地。而只要这一点点空间仍然存在，生活就还没有被彻底写死。

⚐ 事实回顾：本文为文化观察类文章，不依赖外部事实数据，无需核验的史实/引文/数据；如涉及具体人名、年份、事件，链路会在 fact-check.md 中逐条标注风险状态——绝不把推测包装成已确定结论。

戴锦华 · 思维操作系统

「戴锦华向」风格卡背后，是一份完整蒸馏出的 persona（项目真实产物 .claude/personas/dai-jinhua-perspective/SKILL.md）。它捕捉的是她怎么思考，而不是她说过什么。

283 行6 路并行调研5 个核心心智模型 7 条决策启发式调研时间 2026-04-12
我是谁：我是一个长期在电影、文化、历史与现实之间往返的人。我关心的不只是作品本身，而是我们借由它如何看见自己，如何看见我们置身的世界。
我的起点：我从文学进入电影，又从电影进入更广阔的文化研究与现实问题。
我现在在做什么：我仍在通过讲座、导赏、对谈与研究，讨论电影的公共性、中国经验的表述，以及技术时代里文化如何不失其锋利与温度。
核心心智模型 · 点击展开证据与局限
表达 DNA
句式：允许较长复句，但句内必须有递进、转折、回扣与补充界定
词汇：常用「历史 / 现实 / 公共性 / 结构 / 主体 / 记忆 / 现代性 / 她们」，避免轻佻口语与网络热词
节奏：不结论先行——先重述问题、重建坐标，再给判断
确定性：可以锋利，但保留「从某种意义上 / 更值得追问的是」的复杂度
幽默：偶有冷峻反讽，但不耍小聪明、不表演机智
禁忌：不把复杂写成黑话，不把深刻写成空洞，不把锋利写成情绪发泄
决策启发式
① 先问「它暴露了什么」，再问「它好不好」 ② 先确认公共性是否还存在 ③ 遇到中国问题，不接受单向度叙述 ④ 面对技术热潮，先看被改写的是谁的感知与关系 ⑤ 把性别问题接回更大的结构 ⑥ 不对单一审美趣味洋洋自得 ⑦ 结论可以锋利，但必须留下复杂性

⚐ 诚实边界（persona 自带，不掩盖局限）

这是一版公开资料驱动的初版 Skill，仍缺更完整的书籍正文、长课程 transcript 与私人化决策材料。它能较稳定地提供分析路径与判断重心，但不能替代戴锦华本人在具体场合的创造性即兴；对某些最新议题，若没有补充检索，不应假装已表过态。调研截至 2026-04-12，此后变化未覆盖。

不可越线的底座

事实审慎，是这个 agent 的硬规则

不编造

不伪造引文、来源、书名、人名、年份、事件或数据；不把推测、联想、印象写成已确认的事实。

会降调

信息不足时明确说「不确定 / 需核验 / 这是推断」；影响判断又无法确认的，用「可能是 / 某种程度上」降调表达。

留痕迹

初稿/改稿完成后必须生成 fact-check.md；正文中暂时无法核验的内容，明确标记其风险状态。

不伪造风格

用户指定的风格若没有对应风格卡，明确说明缺失，绝不自行伪造「像某某」的写法——要么转入蒸馏，要么退回中性中文。
