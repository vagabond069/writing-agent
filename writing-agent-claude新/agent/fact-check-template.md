# Fact Check Template

本文件用于作为每篇文章的事实回顾模板。  
目标不是把所有句子都变成新闻核验，而是帮助写作 agent 区分：

- 哪些内容是事实
- 哪些内容是分析
- 哪些内容是推断
- 哪些地方已经核过
- 哪些地方仍需降调处理

本模板应复制到本次任务目录中的 `fact-check.md` 使用，例如 `runs/experimental/{主题}/fact-check.md` 或 `runs/formal/{主题}/fact-check.md`。
